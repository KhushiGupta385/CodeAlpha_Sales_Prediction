# CodeAlpha_Sales_Prediction

## 📊 Sales Prediction Using Machine Learning

This project was completed as part of my **Data Science Internship at CodeAlpha**.

The objective of this project is to analyze advertising data and predict product sales using **Python and Linear Regression**.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## 📁 Dataset

The dataset contains advertising expenditure on:

- TV
- Radio
- Newspaper

The target variable is **Sales**.

## 🔍 Project Steps

1. Loaded the dataset
2. Performed data cleaning and preprocessing
3. Checked missing values
4. Performed statistical analysis
5. Performed correlation analysis
6. Created data visualizations
7. Analyzed relationships between advertising and sales
8. Built a Linear Regression model
9. Evaluated the model using R² Score and Mean Squared Error
10. Compared actual and predicted sales
11. Made a sample sales prediction

## 📈 Model Performance

- **R² Score:** Approximately 0.90
- **Mean Squared Error:** Approximately 3.17

The model shows a good relationship between advertising expenditure and sales.

## 💡 Key Insights

- TV advertising has the strongest relationship with Sales.
- Radio advertising also shows a positive relationship with Sales.
- Newspaper advertising has a weaker relationship with Sales.
- The Linear Regression model achieved an R² score of approximately 0.90.
- Actual and predicted sales values are reasonably close.

## 📌 Conclusion

This project demonstrates how machine learning can be used to analyze advertising data and predict sales. Linear Regression provided a good prediction performance for this dataset.
